# Executive Summary & Profitability Dashboard | Excel

An interactive Excel dashboard built with **Pivot Tables, Pivot Charts, and Slicers** to explore sales performance and profitability across months, countries, sales channels, regions, and product categories.

> This is a hands-on learning project created to practice Microsoft Excel, data analysis, and dashboard design.

## Project Objective

The objective of this project is to turn sales transaction data into an interactive executive summary. The dashboard helps users review key performance indicators (KPIs), explore revenue and gross profit trends, compare country and regional performance, and filter the analysis by product category, country, and quarter.

## Dashboard Features

- **Monthly Revenue and Gross Profit:** Compares revenue and gross profit across January to December.
- **Top 5 Countries by Revenue:** Compares revenue across the five countries highlighted in the dashboard.
- **Revenue by Sales Channel:** Shows the contribution of Corporate, Marketplace, Online Store, and Retail Partners.
- **Region-wise Comparison:** Compares Central Europe, Northern Europe, Southern Europe, and Western Europe.
- **Country-wise Map Chart:** Visualizes revenue by country.
- **Interactive Slicers:** Filter the dashboard by Product Category, Country, and Quarter (Q1–Q4).
- **Navigation Buttons:** Includes buttons for the Dashboard and supporting Pivot Tables views.

## Workbook Structure

The Excel workbook contains three worksheets:

| Worksheet | Purpose |
|---|---|
| `Dashboard` | Main interactive executive summary and profitability dashboard. |
| `Pivot Table` | Supporting Pivot Table summaries and KPI calculations used by the dashboard. |
| `Data` | Source sales transaction data used for the analysis. |

### Data Fields

The source data includes fields such as Order Date, Year, Quarter, Month, Region, Country, Sales Channel, Customer Type, Product Category, Product, Units Sold, Unit Price, Discount %, Unit Cost, Revenue, COGS, Gross Profit, and Gross Margin %.

## How to Use

1. Download or clone this repository.
2. Open `Excel Sales Dashboard(1).xlsx` in Microsoft Excel.
3. Select the `Dashboard` worksheet to view the dashboard.
4. Use the **Product Category**, **Country**, and **Quarter** slicers to filter the dashboard.
5. Select the `Pivot Table` worksheet to review the supporting summaries, or the `Data` worksheet to inspect the source records.

> For the best interactive experience, open the workbook in the desktop version of Microsoft Excel. Compatibility of Pivot Tables, slicers, and map charts may vary in other spreadsheet applications.
